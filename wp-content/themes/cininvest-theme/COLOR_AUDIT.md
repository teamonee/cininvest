## 5. Оставлено под вопросом

1. **`--c-line: #E4E4E4`** — в Figma нет отдельной переменной для границ
   (макет почти не использует рамки, только тени/заливки). Значение похоже
   на «Номер пункта» (#E5E5E5), но не совпадает точно (E4 vs E5). Не менял —
   не с чем сверить напрямую, риск ухудшить без источника истины.
2. **`.buy__total{background:#d9a7a7}`** (project.css) — визуально близко к
   Figma-переменной «Бледно-розовый» (#CB9999), но не совпадает точно, а сам
   узел с этой переменной в макете не найден (нет применений). Не менял —
   нужна ручная сверка с дизайнером/точным узлом модалки покупки.
3. **`#F1F1F1`** («Фон под текст» в Figma) используется в `.dropzone`,
   `.check-card`, `.passport-card` — токена под это значение в `:root` нет.
   Не заводил новую переменную (не входило в список токенов задания) —
   значение верное, просто не вынесено в `--var`.
4. **Иконки операций** (`.reward__icon`, `.operation__icon--*`:
   `#E23,#B00`, `#F6D200,#C9A800`, `#3CC13B,#1E8A2E`, `#33B7E8,#127BB5`) —
   похожи на смежные оттенки красного/жёлтого/зелёного/синего, но это
   отдельная декоративная палитра типов операций, не бренд-токены —
   не трогал.
5. **rgba с прозрачностью, совпадающие по RGB с токенами** —
   `.fund-card__glow{background:rgba(183,0,0,.3)}` (=`--c-primary` с альфой,
   мобильный красный глоу) и `.fund-card{background:rgba(229,229,229,.4)}`
   (=`--c-grey` с альфой, desktop-стекло) — оставлены как есть по явному
   исключению задания (стекло/прозрачность).

## 6. Проверка после правок

Прочитаны все 7 файлов целиком после замен, скобки `{`/`}` сбалансированы
в каждом файле (проверено построчным подсчётом). Визуальный прогон в
браузере (главная/проект/профиль) не выполнялся в рамках этой сессии —
изменения носят чисто «переменная вместо идентичного хардкода» характер
(значения не менялись, кроме 3 токенов из п.2, которые были приведены
к уже повсеместно использовавшемуся в коде фактическому значению), поэтому
визуального регресса не ожидается, но рекомендуется ручная проверка на
390/768/1440 при следующей возможности открыть сайт в браузере.
