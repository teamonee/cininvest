## ⚠️ Важное ограничение

Аудит собирался параллельно по всем страницам. В процессе аккаунт Figma MCP упёрся в **лимит вызовов тарифа Starter** («You've reached the Figma MCP tool call limit on the Starter plan»). Это жёсткий лимит на уровне аккаунта, не временная ошибка — часть страниц успела свериться полностью, часть только частично (структура/размеры без точных цветов и типографики), часть — вообще не успела получить ни одного ответа от Figma.

Ниже каждая страница помечена статусом:
- ✅ **проверено** — расхождения подтверждены реальными данными макета
- 🟡 **частично** — часть блоков подтверждена, часть не успели проверить (указано отдельно)
- ⛔ **не проверено** — лимит исчерпался до начала работы по странице, таблицы нет

Для страниц со статусом ⛔/🟡 значения из макета не додумывались (по правилу CLAUDE.md «Значения брать из Figma, а не додумывать»). Рекомендация: повторить аудит этих страниц после сброса лимита/апгрейда тарифа Figma MCP.

Критичность:
- **высокая** — видно сразу: поехала раскладка, обрезан текст, не тот шрифт/цвет, перекрытие
- **средняя** — заметно при сравнении: размеры, вес шрифта, радиусы
- **низкая** — отступы в пределах нескольких пикселей
