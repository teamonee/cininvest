# CININVEST — WordPress тема

Инвестиционная платформа для кинопроектов (краудфандинг/краудинвестинг).

## Требования
- WordPress 6.0+
- PHP 7.4+
- Плагин **ACF (Advanced Custom Fields)** — обязателен для полей проектов (`inc/acf-fields.php`)

## Установка
1. Скопировать папку `cininvest-theme` в `wp-content/themes/`.
2. Установить и активировать плагин ACF (бесплатная версия).
3. Активировать тему в админке — установщик (`inc/theme-setup.php`, хук `after_switch_theme`)
   сделает всё сам:
   - создаст таблицу `wp_cininvest_operations`;
   - создаст страницы и назначит им шаблоны (Атрибуты страницы → Шаблон), если страницы с таким
     slug ещё нет: `/login/` → Вход, `/register/` → Регистрация, `/application/` → Подача заявки,
     `/application-sent/` → Заявка отправлена, `/verification/` → Верификация,
     `/verification-checking/` → Проверка данных, `/verification-done/` → Верификация завершена,
     `/qualification/` → Квалификация инвестора, `/faq/` → FAQ, `/docs/` → Документы,
     `/for-cinematographers/` → Для кинематографистов, `/for-investors/` → Для инвесторов,
     `/profile-investor/`, `/profile-sponsor/`, `/profile-cinematographer/` → шаблоны профиля;
   - создаст страницу «Главная» и выставит её статической главной (front-page.php подключится
     автоматически);
   - создаст меню «Главное меню» (Наша платформа / Проекты / FAQ / Документы) и привяжет его к
     шапке — если меню в локации `primary` уже есть, установщик его не трогает;
   - сбросит правила ЧПУ, поэтому `/projects/` (архив CPT `project`, шаблон `archive-project.php`
     — отдельной страницы под витрину больше нет) заработает сразу.

   Установщик идемпотентен — повторная активация не плодит дублей страниц/меню. Принудительно
   прогнать его заново: `wp eval 'cininvest_reset_setup();'`, затем деактивировать/активировать тему.
4. Если после этого `/projects/` или другие ЧПУ всё же не открываются (например, тему не
   переактивировали, а обновили файлами поверх) — Настройки → Постоянные ссылки → Сохранить.
5. Заполнить хотя бы один проект (Проекты → Добавить) с ACF-полями.
6. Присвоить пользователю роль вручную (до готовности формы саморегистрации с авто-присвоением):
   user meta `cininvest_role` = `investor` / `sponsor` / `cinematographer`.

## Архитектура
- `inc/` — весь бэкенд: CPT, ACF-поля, таблица операций, платёжный слой (заглушка + интерфейс
  под будущий банк), профили пользователя, формы (регистрация/вход/заявка/верификация/покупка долей),
  REST-вебхук для банка.
- `template-parts/` — переиспользуемые блоки (главная, заявка, проект, кошелёк, модалки).
- `assets/` — CSS вшит в `style.css`, JS в `assets/js/main.js`, изображения — placeholder'ы
  (замените на реальные). Шрифты локальные (`assets/fonts/`):
  **Montserrat** (variable, основной текст) и **Palui SP Demo Bold** (капс-заголовки).

### ВАЖНО про Palui SP Demo
Это demo-версия шрифта: в ней есть кириллица и латиница, но **цифры — глифы-заглушки
(пустые прямоугольники), а символы `%` и `₽` отсутствуют вовсе**. Поэтому все числовые
значения (суммы, проценты, номера шагов, показатели) принудительно набираются Montserrat.
Если купите полную версию Palui — замените .woff2 и при желании верните числа на дисплейный
шрифт (класс-утилита `.num` в style.css).

## Платёжный слой
Все операции с деньгами идут через `cininvest_gateway()` (интерфейс `CININVEST_Payment_Gateway`).
Сейчас активна заглушка `CININVEST_Mock_Gateway` — работает "по-настоящему" (баланс, история),
но без реального банка. Чтобы подключить банк: создать класс, реализующий интерфейс, и переключить
провайдера через фильтр `cininvest_payment_provider`. Вебхук для банка: `inc/rest-webhook.php`
(REST `/wp-json/cininvest/v1/payment-callback`), требует секрет в опции `cininvest_webhook_secret`.

## Известные ограничения (см. диалог сборки)
- Palui SP Demo — demo-версия без цифр/%/₽ (см. раздел про шрифты выше).
- Email-уведомления и антиспам (reCAPTCHA) не подключены.
- Реальное подтверждение верификации (checking → completed) — заготовка, ждёт банк/провайдера проверки.
- Модалки "Пополнить" на кошельке используют базовую форму — можно расширить полем суммы.
